Database Data Dictionary

Interactive physical schema documentation for the FurEver PawCare PostgreSQL database.

Identity & Profile Domain

users

Stores primary credentials, security states, profiles, and contact channels for all registered clients, clerk admins, and doctors.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
user_id String UUID PK uuid_generate_v4() Unique account identifier mapping.
full_name String VARCHAR - - Full legal name of the user.
email String VARCHAR UK - Unique email used for login credentials.
password String VARCHAR - - Salted and hashed password.
phone_number String? VARCHAR - NULL Optional contact phone number.
address String? TEXT - NULL Optional billing/shipping street address.
role Role ENUM - 'USER' Account role privileges. Values: USER, ADMIN, SUPER_ADMIN.
profile_image String? VARCHAR - NULL Optional URL/file path to user avatar.
created_at DateTime TIMESTAMPTZ - NOW() Record registration timestamp.
updated_at DateTime TIMESTAMPTZ - - Auto-updating edit timestamp.

admin_staff

Holds extended administrative/employment details linked one-to-one with a primary user account.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
user_id String UUID PK, FK - References users.user_id. Cascade delete.
employee_code String VARCHAR UK - Unique staff code identifier.
position String VARCHAR - - Employment position (e.g. 'Lead Vet', 'Clerk').

Clinical & Telehealth Domain

pets

Stores details of registered pets linked to their owner's user account.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
pet_id String UUID PK uuid_generate_v4() Unique pet record ID.
user_id String UUID FK - References users.user_id (pet owner).
pet_name String VARCHAR - - Name of the pet.
species String? VARCHAR - NULL Optional species classification (e.g. 'Dog', 'Cat').
breed String? VARCHAR - NULL Optional breed specification.
age Int? INTEGER - NULL Optional age in years.
gender String? VARCHAR - NULL Optional pet gender.
weight Float? DOUBLE PRECISION - NULL Optional weight in kilograms.
avatar String? VARCHAR - NULL Optional URL/file path to pet photo.
is_archived Boolean BOOLEAN - false Indicates if this pet has been soft-archived.

pet_monitoring

Stores triage data and health telemetry, managing continuous pet diagnostics.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
monitor_id String UUID PK uuid_generate_v4() Unique monitoring record ID.
pet_id String UUID FK - References pets.pet_id.
monitoring_status MonitoringStatus ENUM - 'ACTIVE' Current health tier. Values: ACTIVE, RESOLVED, CRITICAL.
symptoms String? TEXT - NULL Logged physiological symptoms.
behavior_changes String? TEXT - NULL Noticed mood variations.
is_forwarded Boolean BOOLEAN - false Toggled if escalated from admin to vet.
chat_messages Json? JSONB - NULL Optional diagnostic conversation raw payload logs.

E-Commerce Domain

products

Details the items available for sale in the online veterinary e-commerce store.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
product_id String UUID PK uuid_generate_v4() Unique catalog stock SKU number.
product_name String VARCHAR - - Retail item catalog name.
category String VARCHAR - - Subgroup categorizations (e.g. 'Food').
price Float DOUBLE PRECISION - - Retail unit base price.
stock_quantity Int INTEGER - - Count of items in warehouse.
status ProductStatus ENUM - 'AVAILABLE' State of catalog availability. Values: AVAILABLE, OUT_OF_STOCK, DISCONTINUED.
is_archived Boolean BOOLEAN - false Whether catalog item has been soft-archived.

Financial & Billing Domain

payments

Main ledger mapping financial clearances of checkouts, appointments, and telemetry diagnostics.

Column Name Prisma Type PostgreSQL Type Keys Default Description / Constraints
payment_id String UUID PK uuid_generate_v4() Unique financial txn receipt key.
order_id String? UUID FK NULL Optional billing reference to orders.
appointment_id String? UUID FK NULL Optional billing reference to appointments.
telemed_id String? UUID FK NULL Optional billing reference to telemedicine.
payment_amount Float DOUBLE PRECISION - - Paid currency decimal sum.
payment_status PaymentStatus ENUM - 'PENDING' Clearing stage. Values: PENDING, COMPLETED, FAILED, REFUNDED.
reference_number String? VARCHAR - NULL Optional reference codes from GCash/E-Wallet.

Custom Database Enums

Role

  • SUPER_ADMIN — Full system permissions
  • ADMIN — Clinic staff & receptionist
  • USER — Regular pet owners & shoppers

AppointmentStatus

  • PENDING | CONFIRMED
  • COMPLETED | CANCELLED
  • PAID | DECLINED

MonitoringStatus

  • ACTIVE — Diagnostic cycle running
  • RESOLVED — Treated & healthy pet
  • CRITICAL — Flagged for emergency care

PaymentStatus

  • PENDING | COMPLETED
  • FAILED | REFUNDED
